# Horizon

Future possibilities for Legatus that are not in the v1 plan. Each entry records what the idea is, why it might matter, what was checked and what was not, and what would trigger picking it up. Nothing here is a commitment, and nothing here changes the specs under [`specs/`](../../specs/README.md).

How to read an entry: **Checked** means someone read a source or ran something and the entry says which. **Not tested** means the claim is a reading of documentation or a guess. Nothing in this folder has been run against Legatus.

| Entry | What | Status | Last reviewed |
|---|---|---|---|
| [Open WebUI](openwebui.md) | Use Open WebUI, a self-hosted multi-user chat UI with sub-agents, as a client of Legatus | Researched from documentation, not run | 2026-10-06 |

## Adding an entry

One file per idea, named for the idea. Each file has these sections: what it is, why it might matter, how it could work with Legatus, what it exposes or breaks in the current design, what was checked and what was not, the trigger to pick it up, and sources. Add a row to the table above.
