# Spike 1b: pi 1.0.3 lease gaps (fakes only: NO real model, NO model lock)

Versions: pi-coding-agent 1.0.3 installed (npm latest 1.0.4, project target 1.0.3), pi-subagents 0.76.0 (latest 0.76.1), node 24.15.0, openai SDK 7.19.0, @anthropic-ai/sdk 0.129.0 (bundled). Checked with `npm view` 2026-10-06 (`latest-versions.txt`). Everything here ran against fakes: `fakeb.mjs` (scripted OpenAI chat + Anthropic Messages fake LLM, records every request header/body), `adminb.mjs` (fake Legatus admin, logs every call), `rewrite.mjs` (stand-in router that rewrites `model`). Originals in `../s1-pi-lease/` untouched.

Layout. `ext/lease.ts` = unmodified copy of spike 1's extension (used for the core proofs). `ext/lease_b.ts` = same plus env-flagged extras (see header comment): setModel after acquire, required-child registration, lease sharing (global / file / pool), binding injection on `subagent` tool_call, affinity minting, acquire deadline, non-owner shutdown. `fake.mjs`, `admin.mjs`, `trials.sh` = copies of the originals (trials.sh is the real-model harness, NOT run). `lib.sh` = harness; `t01..t13*.sh` = the test scripts (each starts and stops its own fake+admin with pid files, ports 18900/18901/18903).

Every run = one never-overwritten directory `runs/<UTC timestamp>-<name>/` containing: `cmd.txt` (exact pi command, cwd, timeout), `versions.txt`, `env.txt`, `fake-requests.jsonl` (every request: full headers, body, scripted behaviour), `admin-calls.jsonl` (every admin call with response), `ext.jsonl` (extension event log), `main.out/.err/.rc` (pi output, exit code, wall ms), plus `rpc.log` / `sig.log` / `admin-state-*.json` where relevant, and the isolated `agent/` dir (models.json, settings.json, session files). The fake's queue script is visible per request in the `behavior` field. Paths below are relative to `runs/`. Run `. lib.sh; RUN=<dir>; hdrs` to print the header timeline of any run.

Harness-error runs that I deleted (no pi evidence in them): first `compaction-rpc` attempt (PI not exported), first `two-children-global` (parallel direct subagent calls are rejected by pi-subagents), first `child-self-acquire-wf` x2 (bad workflow script API), first `async-...-mint0` (flag bug). Kept on purpose although "wrong": `223401Z-compaction-manual` (ctx.compact aborts the running turn: "Compaction cancelled"), `223849Z-child-fg-global` and `223855Z-child-fg-file` (show the child releasing the PARENT's lease: a real hazard, fixed in the later runs), `223740Z-anthropic-messages-path` (no affinity compat flag).
