## What Legatus is now (so you test the right thing)
A heterogeneous proxy that matches a subagent TASK with a local inference resource and owns allocation of the LLM pool only. Router (Rust) serves OpenAI chat-completions and Anthropic Messages, role in the `model` field (e.g. `legatus/role/coder`), pins a conversation to a node on `x-session-affinity`, and holds LEASES: a lease is a slot on one node for the life of a subagent task. Explicit acquire in v1: the host agent calls tools `can_spawn` (non-binding capacity preflight) and `request_llm` (acquire) before spawning a subagent and `release_llm` at the end; later model calls carry `x-legatus-lease: <id>` (and `x-session-affinity`). Admin routes (HTTP JSON): `POST /legatus/v1/capacity`, `GET /legatus/v1/pool`, lease acquire/release/list; release takes the holder value and only the holder can free its lease (`lease_not_yours` 409); a lease ends on release, idle TTL (PROPOSED 1800 s) or max lifetime (PROPOSED 14400 s); a request on an ended lease gets 409 `lease_ended`; a pinned node that is unavailable returns 503 `bound_node_unavailable`; a router restart replays a journal and serves after replay (listening early, answering health 503 until ready). No router timeouts, retries or failover in v1: failures go to the agent.
